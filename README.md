# SteamX_Future_Engineers_2026
Even after going through the war and not being able to be present at "SteamX Robotics club" for 4 months to work and prepare for the WRO, we still decided to paticipate and work on this competition in the time we have left (slightly less than 2 weeks) and we plan to put all our effort and energy into this competition the rest or the README file will explainm the process of preperation:

1. Process of Assembly of the Robot and Distribution of the Tasks
   Firstly, a team meeting was held to discuss the distribution of tasks between the team members (Yehya Hariri, Salim Daher, Ahmad Damoori, Suleiman Soloh,Rayan Sabra, Ali chhimy, Samer Ghousain) this was done so the team would embrace teamwork because they know that teamwork is the key to success, tasks vary and we were distributed as the following:
  * reading the rules (all the team)  
  * designing the robot (2 people)
  * researching the parts needed (1 person)
  * assembling the robot (2 people)
  * programing the robot (1 person)
  * testing the robot (all the team)
  * writing this report (1 person)
   This distribution insured that everyone would play their perfect role in the areas they are the strongest in.

2. The Design
   Two people were given this task, they had to search for the best form this robot can take, to ensure that every component has it's place and for the components to be organized to give the robot a clean look and for the robot to be easily modifiable in case of any error that might take place. Besides the organization the robot's design isn't anything special, it's the basic car design known by everybody. Finally the robotdesign complies with all the rules and isn't a centimeter longer than the measurements mentioned in the rules. The design features a "Box shaped rectangular design" with 4 wheels, and a hollow inside, the dimentions are length = 29.9cm, hight = 17cm, and width = 16cm and the robot is symmetric and balanced. Built using legos the robot" chasis is also very durable and very stable.
   
3. Researching The Parts Needed
   This task was handled by one person to research every part thats needed for the robot such as the battery, microcontroler, AI lense, motors, ect... that comply with the specifications needed. Some parts weren't available like some certain lego pieces for the steering mechanisim sothe team 3D printed these parts.

4. Assembling The Robot
   This task was handled by two people to ensure precision during the assembly process, making the robot free from error and professionally assembled reducing the risk factor during the competition, but even though the robot was assembled perfectly emergency measures were taken in case of any problem that might occuror for any modification that might be implemented last minute thus making the robot highly customizable.

5. Programing The Robot
   This task was given to one person, who built every line from scratch not a line taken from outside sources not a line taken from AI, every line was hand typed, every mistake was corrected, not a single flaw in the code, every line has a perfect relation to one under it, the code runs smoothly without stoping a for a second to rest.

6. Testing The Robot
    From the beginning of the report and you've been hearing about how perfect the robot is and all this pefection is because we learned from our mistakes during the first test drive which was a catastrophy, the mistakes which ruined the robot weren't only fixed but perfected down to the last detail, and while fixing these flaws many more test drives were taken in between to make sure everything was 100% fixed. A test drive was done around 20 mins ago to test the robots abilities and it showed great results, round one's code will be provided asa seperate file on this repo
